# Project management documentation

This repository's root README is the current source for product scope, features, technology stack, setup, and known limitations. It describes Harbour & Oak as a bilingual English/Spanish property portal for an Irish estate agency with a staff back office.

## Documentation plan

Add focused documents here as verified project information becomes available:

- Product brief, boundaries, and acceptance criteria
- Roadmap and release notes
- Architecture decisions
- Risks, assumptions, and dependencies
- Delivery and retrospective notes

## Public documentation boundary

Keep public product documentation separate from staff-only and operational data. Never add customer enquiries, seller contact details, access instructions, keys or alarm codes, internal legal notes, production data, credentials, or secrets. Check claims against the current code or root README, and label proposals as proposals.
